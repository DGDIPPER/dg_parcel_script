**dg_parcel_script** is a simple and clean FiveM resource that allows players to open a parcel/box item and receive configurable rewards.  
Fully compatible with **QBox** and **ox_inventory**, and powered by **ox_lib**.

Perfect for loot boxes, delivery parcels, mystery crates, starter packs, or reward packages.

## ✨ Features

- 📦 Open parcel/box usable item
- 🎁 Configurable reward items
- 🎲 Random reward support
- ⚙️ Easy config setup
- 🖥️ ox_lib notifications/UI
- 📦 ox_inventory usable item
- 🧩 Qbox compatible
- 🚀 Lightweight & optimized

---

## ✅ Requirements

- qbx_core  
- ox_inventory  
- ox_lib  

Make sure dependencies are updated.

---

## 📦 Installation

1. Download `dg_parcel_script`
2. Place into your `resources` folder
3. Ensure correct start order:

```cfg
ensure ox_lib
ensure ox_inventory
ensure qbx_core
ensure dg_parcel_script
